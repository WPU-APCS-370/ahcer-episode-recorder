# Time Log

A running record of time spent working on this app with Claude Code. See
the "Time tracking" section of `CLAUDE.md` for how this is maintained.

Each row's duration is real wall-clock time between a captured start and
end timestamp for that session — not an estimate. A session that spans a
long gap (e.g. paused overnight) will show that gap in its duration; note
that in the Notes column rather than trying to net it out, since the
timestamps themselves are the accurate part.
